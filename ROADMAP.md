# Learning roadmap

This is a suggested learning order, not a deadline. Later stages contain a mix of difficulties to introduce each topic gently before harder practice.
Before each stage: explanation, Java building blocks, a traced example, and a concept check.

| Stage | Concepts to learn first | LeetCode problems in suggested order |
| --- | --- | --- |
| 1. Arrays and loops | indexes, length, traversal, accumulator, returning arrays | 1480 Running Sum of 1d Array; 1929 Concatenation of Array; 1295 Find Numbers with Even Number of Digits; 1672 Richest Customer Wealth |
| 2. Strings | charAt, length(), StringBuilder, character comparisons | 344 Reverse String; 125 Valid Palindrome; 242 Valid Anagram; 14 Longest Common Prefix |
| 3. Maps and sets | HashMap, HashSet, counts, membership | 217 Contains Duplicate; 1 Two Sum; 383 Ransom Note; 49 Group Anagrams |
| 4. Two pointers | left/right positions, sorted arrays, in-place changes | 283 Move Zeroes; 26 Remove Duplicates from Sorted Array; 167 Two Sum II - Input Array Is Sorted; 11 Container With Most Water; 15 3Sum |
| 5. Binary search | sorted search space, midpoint, boundary updates | 704 Binary Search; 35 Search Insert Position; 69 Sqrt(x); 33 Search in Rotated Sorted Array |
| 6. Prefix sums and windows | range sums, fixed and variable windows | 724 Find Pivot Index; 643 Maximum Average Subarray I; 209 Minimum Size Subarray Sum; 3 Longest Substring Without Repeating Characters; 560 Subarray Sum Equals K |
| 7. Linked lists | references, nodes, next, dummy nodes | 206 Reverse Linked List; 21 Merge Two Sorted Lists; 876 Middle of the Linked List; 141 Linked List Cycle; 19 Remove Nth Node From End of List |
| 8. Stacks and queues | LIFO/FIFO, ArrayDeque, matching, monotonic stacks | 20 Valid Parentheses; 232 Implement Queue using Stacks; 155 Min Stack; 739 Daily Temperatures |
| 9. Recursion and trees | base case, call stack, DFS, BFS | 104 Maximum Depth of Binary Tree; 226 Invert Binary Tree; 100 Same Tree; 102 Binary Tree Level Order Traversal; 98 Validate Binary Search Tree |
| 10. Heaps and intervals | PriorityQueue, comparators, sorting interval endpoints | 703 Kth Largest Element in a Stream; 215 Kth Largest Element in an Array; 56 Merge Intervals; 435 Non-overlapping Intervals |
| 11. Backtracking | choices, recursion, undoing choices | 78 Subsets; 46 Permutations; 39 Combination Sum; 79 Word Search |
| 12. Graphs | adjacency lists, visited set, DFS/BFS, dependencies | 733 Flood Fill; 200 Number of Islands; 994 Rotting Oranges; 207 Course Schedule |
| 13. Dynamic programming | states, transitions, memoization, tabulation | 509 Fibonacci Number; 70 Climbing Stairs; 198 House Robber; 322 Coin Change; 300 Longest Increasing Subsequence; 1143 Longest Common Subsequence |
| 14. Advanced practice | combine patterns; learn tries and greedy reasoning as needed | 23 Merge k Sorted Lists; 42 Trapping Rain Water; 76 Minimum Window Substring; 84 Largest Rectangle in Histogram; 124 Binary Tree Maximum Path Sum; 212 Word Search II; 72 Edit Distance |

Learn time and space complexity gradually, starting with a single loop in stage 1.
Revisit difficult problems after a few days and explain the approach without looking at your old code.
