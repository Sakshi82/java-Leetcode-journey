# Java LeetCode Journey

Started: **23 October 2026**

A beginner-to-advanced learning journey, one concept and one problem at a time.

## How we learn

1. Learn the topic in plain language with a small Java example.
2. Answer a concept check before starting the problem.
3. Try the problem yourself. Ask for hints when stuck.
4. Review your approach, trace an example, and discuss time and space usage.
5. Test the solution, submit it to LeetCode, and record the actual result.
6. Commit and push your reviewed solution and notes.

Aim for one problem per session at first. Understanding matters more than speed.
We move to a new topic when you can explain the current idea and solve a similar problem with little help.

## Saving solutions

Use a folder such as `solutions/1480-running-sum-of-1d-array/` containing `Solution.java` and `NOTES.md`.
Each problem has its own folder because LeetCode generally uses the class name `Solution`.
Compile one problem at a time. LeetCode supplies its own runner; you usually do not need a `main` method there.

Share your code and any LeetCode submission result in our chat. We will review and push completed work here.
Local tests and LeetCode acceptance are recorded separately; neither is assumed.
