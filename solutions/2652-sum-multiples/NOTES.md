# 2652 — Sum Multiples

- Problem: https://leetcode.com/problems/sum-multiples/
- Topic: Loops, remainder, logical OR, and a running sum
- LeetCode result: Accepted (learner-reported).
- Solution: Learner's submitted code, formatted for readability.

Check each integer from 1 through `n`. If its remainder is zero when divided by 3, 5, or 7, add it once to `sum`. The `||` operator makes the condition true when any one of the divisibility checks succeeds.

Time: O(n). Extra space: O(1).
