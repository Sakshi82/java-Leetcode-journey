# 2469 — Convert the Temperature

- Problem: https://leetcode.com/problems/convert-the-temperature/
- Topic: `double`, arithmetic, and returning an array
- LeetCode result: Accepted (learner-reported).
- Solution: Learner's submitted code, formatted for readability.

Calculate Kelvin and Fahrenheit from the given Celsius value, then return them in the required order: Kelvin first, Fahrenheit second. The return expression creates a `double[]` containing both values.

Time: O(1). Extra space: O(1), excluding the returned array.
