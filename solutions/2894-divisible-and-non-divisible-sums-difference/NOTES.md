# 2894 — Divisible and Non-divisible Sums Difference

- Problem: https://leetcode.com/problems/divisible-and-non-divisible-sums-difference/
- Topic: Loops, remainder, and two running sums
- LeetCode result: Accepted (learner-reported).
- Solution: Learner's submitted code, formatted for readability.

Visit each integer from 1 through `n`. If `i % m == 0`, add it to `num2`; otherwise, add it to `num1`. Return the non-divisible sum minus the divisible sum.

Time: O(n). Extra space: O(1).
