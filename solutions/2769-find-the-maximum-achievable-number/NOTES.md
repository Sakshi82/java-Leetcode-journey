# 2769 — Find the Maximum Achievable Number

- Problem: https://leetcode.com/problems/find-the-maximum-achievable-number/
- Topic: Understanding the effect of repeated operations
- LeetCode result: Accepted (learner-reported).
- Solution: Learner's submitted code, formatted for readability.

Each move can increase the target value by 2 while the comparison value decreases by 1. Repeating this for `t` moves gives `num + 2 * t`.

Time: O(1). Extra space: O(1).
